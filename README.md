# 🎨 ParticlePortrait – Creative Coding Project

A cinematic particle-based portrait drawing animation built using **HTML, CSS, JavaScript, and Canvas API**.

This project transforms a portrait image into a dynamic particle artwork where thousands of animated particles progressively draw the image before smoothly revealing the original photograph.

## ✨ Features

* Particle-based portrait reconstruction
* Progressive drawing animation
* Smooth cinematic transitions
* Canvas API powered rendering
* Responsive design
* Lightweight frontend implementation
* Original image reveal effect
* Creative coding showcase project

## 🚀 Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Canvas API

## 🎬 Animation Flow

1. Portrait remains hidden initially.
2. Tiny particles begin appearing.
3. Particles progressively form image contours.
4. More details are drawn gradually.
5. Complete particle artwork is assembled.
6. Particle artwork smoothly transitions into the original image.
7. Final portrait is displayed in full quality.
